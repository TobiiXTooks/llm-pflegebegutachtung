PflegeBench – Ergebnisdokumentation des Workflows

Diese Ausarbeitung dokumentiert die tatsächlich erzeugten Ergebnisse des aktuellen Projektstands. Jedes Ergebnisartefakt ist dem passenden PflegeBench-Befehl zugeordnet, durch den es erzeugt oder geöffnet wird.

Abgabebereite Ergebnisübersicht Reale Projektausgaben Befehl-zu-Ergebnis-Zuordnung Stand: aktueller Projektordner

Durchgeführter Ergebnislauf

Der vorhandene Benchmark-Datensatz des Projekts wurde gegen die validierten Referenzdateien verglichen. Daraus entstanden konkrete JSON-Reports, Fehler-CSV-Dateien und ein HTML-Dashboard als auswertbare Ergebnisartefakte.

48Modell-Dateien in to_validate
47validierte Referenzdateien
47generierte Report-JSONs
47generierte Fehler-CSVs

Zentrale Einordnung

Ergebnisgrundlage: Die Ausgaben liegen vollständig vorbereitet vor. Dokumentiert sind die verarbeiteten Dateien, die erreichten Genauigkeiten sowie konkrete Abweichungen zwischen Modellantwort und validierter Referenz.

Befehl-Zuordnung der Ergebnisartefakte

Die folgenden Befehle sind direkt den dokumentierten Ergebnisartefakten zugeordnet. Dadurch ist nachvollziehbar, mit welchem Workflow-Schritt jedes Ergebnis technisch erzeugt oder geöffnet wird.

Projektstart

Workflow anzeigen

python -m pflegebench overview

Erzeugt: textuelle Übersicht der empfohlenen Arbeitsreihenfolge.

Erzeugtes Ergebnis: Einstieg in den Ablauf von Datenbasis bis Dashboard.
Setup

Projekt installieren

python -m pflegebench setup --upgrade-pip

Erzeugt: installierte lokale Projektumgebung mit nutzbarem PflegeBench-CLI.

Erzeugtes Ergebnis: Befehle wie python -m pflegebench compare-folder sind ausführbar.
Prüfung

Umgebung prüfen

python -m pflegebench doctor

Erzeugt: konkrete Diagnose zu Python, Paketen, Projektpfaden und API-Keys.

Sichtbar unten in der HTML: Terminal-Ausgabe doctor.
Qualitätssicherung

Dateien prüfen

python -m pflegebench check

Erzeugt: Syntax- und JSON/JSONL-Prüfung des Projektstandes.

Konkretes Ergebnis: 95 JSON/JSONL files, errors: 0.
Datenerzeugung

Modellantworten erzeugen

python -m pflegebench gui-benchmark

Erzeugt: Rohantworten der Modelle für Benchmark-Fälle.

Konkretes Ziel im Projekt: Dateien in data/benchmark/to_validate/.
Datenerzeugung

Getrackte Modellantwort

python -m pflegebench trace --model <openrouter-model-id>

Erzeugt: nachvollziehbare Modellinteraktion mit Trace-Kontext.

Erzeugtes Ergebnis: dokumentierte Antwortgenerierung pro Modell.
API-Test

Modellanbindung testen

python -m pflegebench trace-smoke

Erzeugt: schnellen Funktionstest, ob OpenRouter/Modellaufruf erreichbar ist.

Erzeugtes Ergebnis: vorab prüfen, ob echte Modellgenerierung möglich ist.
Validierung

JSON/JSONL bearbeiten

python -m pflegebench gui-editor

Erzeugt: fachlich korrigierte und bereinigte Benchmark-Dateien.

Konkretes Ziel im Projekt: geprüfte Dateien in data/benchmark/validated/.
Validierung

Browser-Prüftool öffnen

python -m pflegebench eval-html

Erzeugt: browserbasierte Oberfläche zur fachlichen Kontrolle.

Erzeugtes Ergebnis: strukturierte menschliche Bewertung statt reiner Modellausgabe.
Einzelvergleich

Ein Modellfile vergleichen

python -m pflegebench compare --baseline data/benchmark/validated/<datei_v.json> --model data/benchmark/to_validate/<datei.json> --out reports/<report>.json --errors-csv reports/<errors>.csv --key-mode auto

Erzeugt: genau einen JSON-Report und eine Fehler-CSV.

Erzeugtes Ergebnis: Detailanalyse eines konkreten Modelllaufs.
Einzelvergleich

Älteren Vergleich nutzen

python -m pflegebench compare-basic --baseline <validated-file> --model <model-file>

Erzeugt: einfache Vergleichsausgabe mit dem älteren Vergleichsskript.

Erzeugtes Ergebnis: schneller Basisvergleich ohne vollständiges Dashboard.
Batch-Auswertung

Alle passenden Dateien vergleichen

python -m pflegebench compare-folder --validated-dir data/benchmark/validated --model-dir data/benchmark/to_validate --out-dir reports --key-mode auto

Erzeugt: alle Report-JSONs und Fehler-CSVs für die Abschlussdokumentation.

Ergebnis im aktuellen Stand: 47 Vergleiche, 47 Reports, 47 Fehler-CSVs.
Dashboard

HTML-Dashboard erzeugen

python -m pflegebench dashboard --reports reports --out docs/benchmark_dashboard.html --open

Erzeugt: statisches HTML-Dashboard aus den Report-Dateien.

Konkretes Ergebnis: pflegebench_benchmark_dashboard_generiert.html.
Bereitstellung

Dokumentation lokal öffnen

python -m pflegebench docs --port 8000

Erzeugt: lokalen Webserver für die erzeugten HTML-Dateien.

Erzeugtes Ergebnis: Dashboard/Report im Browser präsentieren.
Reset

Generierte Artefakte löschen

python -m pflegebench clean

Erzeugt: sauberen Ausgangszustand für einen neuen Durchlauf.

Erzeugtes Ergebnis: Reports/Dashboard können reproduzierbar neu erzeugt werden.
